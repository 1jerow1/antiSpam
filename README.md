# antiSpam

Telegram-бот для модерации барахолки: удаляет из чата всё, что **не является продажей товара** —
объявления о работе/подработке, услуги, крипту, обмен, рекламу и ссылки.

Классификация — **гибридная**:

- Основной путь — собственный обучаемый ML-классификатор (TF-IDF + логистическая регрессия,
  scikit-learn), который живёт и работает целиком локально и мгновенно.
- Пока модель ещё не обучена или не уверена в конкретном сообщении — решение принимает
  локальная LLM через [Ollama](https://ollama.com/) (`llama3:8b`), как раньше.
- Каждое решение Ollama автоматически сохраняется как новый обучающий пример, поэтому
  датасет пополняется сам по себе по мере работы бота, а ML-модель постепенно берёт на себя
  всё больше решений — Ollama дёргается всё реже.

## Как это работает

1. Пользователь пишет сообщение в чат.
2. Бот пропускает без проверки: администраторов чата, пользователей из whitelist и сообщения с фото.
3. Если ML-модель обучена и уверена в ответе (≥ `ML_CONFIDENCE_THRESHOLD`) — решение принимает она.
   Иначе текст уходит в Ollama с промптом-инструкцией модератора, и её ответ (`SALE`/`NOT_SALE`)
   попадает в датасет (`dataset.jsonl`) как новый обучающий пример.
4. `NOT_SALE` → сообщение удаляется. `SALE` или ошибка Ollama → сообщение остаётся (fail-safe).
5. Администратор может исправлять ошибки классификации командой `/correct` — эти исправления
   тоже идут в датасет и имеют приоритет над автоматическими метками Ollama при обучении.
6. Когда датасет накопил достаточно примеров обоих классов — `/train` обучает модель заново.

Дополнительно:

- **LRU-кэш** ответов Ollama (одинаковые тексты не гоняются повторно).
- **Кэш списка админов** чата на 5 минут.
- **Ограничение параллелизма** запросов к Ollama (семафор на 3).
- **Дневная статистика** (`stats.json`): сколько проверено / оставлено / удалено / решено ML / решено Ollama.

### Важно про приватность

`dataset.jsonl` хранит **тексты сообщений пользователей** (нужно для обучения модели) —
в отличие от `stats.json`, это не просто счётчики. Файл добавлен в `.gitignore` и не должен
попадать в публичный репозиторий или куда-либо ещё. Он живёт только локально на машине,
где запущен бот.

## Требования

- Python 3.11+
- [Ollama](https://ollama.com/) с загруженной моделью:
  ```bash
  ollama pull llama3:8b
  ```
- Бот добавлен в чат **администратором** с правом удалять сообщения.
- В [@BotFather](https://t.me/BotFather) для бота **выключен privacy mode**
  (`/setprivacy` → `Disable`), иначе он не видит обычные сообщения.

## Установка

```bash
git clone https://github.com/1jerow1/antiSpam.git
cd antiSpam
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux / macOS
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```bash
copy .env.example .env        # Windows
# cp .env.example .env         # Linux / macOS
```

| Переменная      | Обязательна | Описание                                            |
|-----------------|-------------|----------------------------------------------------|
| `BOT_TOKEN`     | да          | токен бота от @BotFather                            |
| `ADMIN_ID`      | да          | ваш Telegram user id (узнать у @userinfobot)        |
| `OLLAMA_URL`    | нет         | адрес Ollama API (по умолчанию localhost:11434)     |
| `OLLAMA_MODEL`  | нет         | имя модели (по умолчанию `llama3:8b`)               |
| `MAX_TEXT_LENGTH` | нет       | до скольких символов обрезать текст (по умолчанию 500) |
| `DATASET_FILE`  | нет         | путь к датасету обучающих примеров (по умолчанию `dataset.jsonl`) |
| `MODEL_FILE`    | нет         | путь к обученной ML-модели (по умолчанию `model.joblib`) |
| `MODEL_META_FILE` | нет       | путь к метаданным обучения (по умолчанию `model_meta.json`) |
| `ML_CONFIDENCE_THRESHOLD` | нет | минимальная уверенность ML-модели, чтобы не звать Ollama (по умолчанию `0.85`) |

## Запуск

```bash
python antiSpam.py
```

На Windows можно использовать `run.bat` — он дожидается готовности Ollama и запускает бота.

### Обучение ML-модели

Изначально `model.joblib` не существует — все решения принимает Ollama, а её ответы копятся
в `dataset.jsonl`. Когда там наберётся достаточно примеров обоих классов (SALE и NOT_SALE):

```bash
python train_model.py
```

или прямо в чате командой `/train`. Модель подхватится сразу, без перезапуска бота, и дальше
уверенные решения по новым сообщениям она будет принимать сама, а Ollama останется резервным
вариантом для неуверенных случаев. Периодически переобучайте модель заново (`/train`) по мере
роста датасета — качество классификации будет расти вместе с ним.

## Команды администратора

| Команда           | Где            | Действие                                             |
|-------------------|----------------|-----------------------------------------------------|
| `/whitelist_add`  | реплаем на сообщение пользователя | добавить пользователя в whitelist (его сообщения не проверяются) |
| `/stats`          | в чате         | статистика за сегодня (включая разбивку ML / Ollama) |
| `/mlstats`        | в чате         | состояние ML-модели: обучена ли, точность, размер датасета |
| `/train`          | в чате         | (пере)обучить ML-модель на текущем `dataset.jsonl`   |
| `/pending`        | в чате         | последние удалённые сообщения с их ID (для `/correct`) |
| `/correct sale\|spam` | реплаем на сообщение | исправить классификацию: пометить как SALE/NOT_SALE и добавить в датасет (спам при этом удаляется) |
| `/correct <id> sale\|spam` | в чате   | исправить уже удалённое решение по ID из `/pending` (например, если удалили не спам) |
